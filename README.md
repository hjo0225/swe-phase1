# Blink

로컬 우선(Local-first) AI 노트 데스크톱 앱

## 1. 팀원

- 정보시스템학과 허정오
- 정보시스템학과 박석준

## 2. 한 문장 설명

> 내 폴더에 Markdown으로 쓰는 노트에서, 선택한 부분만 AI로 구체화·정리·시각화하고 과거 노트를 찾아 연결하는 데스크톱 노트 앱

## 3. 주요 화면

### 화면 1. 폴더 보관함과 노트 편집

![화면 1](docs/images/screen-1.png)

처음 실행할 때 고른 폴더가 보관함이 되고, 폴더 구조가 그대로 왼쪽 사이드바 트리로 보입니다. 노트 하나는 `.md` 파일 하나입니다. 본문의 `[[노트 이름]]` 링크를 누르면 그 노트로 이동하고, 아래의 "이 노트를 참조하는 노트"에서 거꾸로 이어진 노트를 볼 수 있습니다. 가운데 그림은 AI 시각화로 만든 인포그래픽(마인드맵)입니다.

### 화면 2. 선택 영역 AI 정리 — 처리 중 Pulse

![화면 2](docs/images/screen-2.png)

문장을 선택하면 `구체화 · 정리 · 시각화` 메뉴가 뜹니다. 요청하면 로딩 창 없이 선택 영역 자체가 천천히 깜빡이며(Pulse) 처리 중임을 알려 줍니다. 그동안 다른 부분은 계속 쓸 수 있고, 결과는 작업이 성공했을 때만 한 번에 적용되며 잠깐 Mint 빛으로 표시됩니다.

## 4. 주요 기능

### 1) 선택한 부분만 AI로 구체화 · 정리 · 시각화

- **구체화**: 웹 검색으로 근거를 찾아 문장을 보강하고, 끝에 실제 출처 링크 목록을 붙입니다.
- **정리**: 흩어진 메모를 제목·목록이 있는 Markdown으로 정리합니다.
- **시각화**: 글의 구조를 분석해 원문 아래에 인포그래픽을 넣습니다. 과정·계층·비교·마인드맵 4가지 유형이 있고 PNG로 저장할 수 있습니다.

AI 작업은 백그라운드에서 처리되고, 처리 중인 범위는 잠겨 있다가 성공했을 때만 한 번에 바뀝니다. 앱을 닫았다 다시 열어도 결과가 들어갈 자리를 잃지 않습니다. AI는 **OpenAI** 또는 **Kimi** 중에서 고르고, 각자의 API Key와 모델로 설정합니다.

### 2) 과거 노트 검색 · 연결 · 가져오기

`Ctrl+K`로 제목과 본문을 함께 검색하면 검색어가 강조된 스니펫이 나옵니다. 결과마다 다음을 할 수 있습니다.

- **열기**: 그 노트로 이동합니다.
- **연결**: 현재 노트에 `[[링크]]`를 넣습니다.
- **내용 가져오기**: 전체 또는 미리보기에서 선택한 부분을 커서 위치에 넣습니다.

링크는 옵시디언과 같은 `[[노트 이름]]` 형식이라 다른 Markdown 앱에서도 그대로 읽힙니다. 노트 이름을 바꾸거나 다른 폴더로 옮기면, 그 노트를 가리키던 다른 노트의 링크도 함께 고쳐집니다.

### 3) 내 폴더에 Markdown으로 저장되는 노트 (보관함)

- 노트 = `.md` 파일, 폴더 = 사이드바 폴더입니다. 사이드바에서 폴더를 만들고, 이름을 바꾸고, 지울 수 있고 노트는 끌어서 옮깁니다.
- 제목이 곧 파일 이름이고, 본문은 입력을 멈추면 자동 저장됩니다. 창을 닫기 직전에 입력한 내용도 보존됩니다.
- 다른 앱에서 파일을 추가하거나 고치면 앱에 바로 반영됩니다. 이미 가진 옵시디언 보관함 폴더를 그대로 열 수도 있습니다.

## 5. 시스템 구조

![시스템 구조도](./images/architecture.png)

사용한 기술들이 어떻게 연결되어 있는지 보여주는 구조도입니다.

- **Renderer**(React · Tiptap)는 화면만 맡고 파일·DB·네트워크에 직접 접근하지 않습니다. **Preload**가 허용된 IPC 채널만 `window.blink`로 노출합니다.
- **Main Process**는 도메인별로 나뉩니다: note(보관함), assist(AI 작업), ai-provider(OpenAI·Kimi 어댑터), visualization(PNG 저장). 모든 요청은 Zod로 검증한 뒤 `{ ok, data | error }` 형태로 응답합니다.
- 노트 원본은 **보관함 폴더의 `.md` 파일**입니다. SQLite에는 검색·링크 색인과 AI 작업 기록(보관함별 DB), AI 설정만 둡니다. API Key는 OS 보안 저장소로 암호화합니다.

> AI를 활용해 제작한 구조도입니다 (이미지 오른쪽 위 `From AI` 표시).

## 7. 실행 환경

- 운영체제: Windows 11 (x64)
- 기타 실행 환경:
  - **설치**: `Blink-Setup-0.1.0.exe`를 실행해 설치하고, 처음 화면에서 노트를 둘 폴더를 고릅니다.
  - **AI 기능**: 인터넷 연결과 OpenAI 또는 Kimi(Moonshot) API Key가 필요합니다. 앱의 `설정`에서 Provider·모델·Key를 입력하고 `연결 테스트` 후 저장합니다. 노트 작성·검색·연결은 Key 없이도 됩니다.
    - Kimi는 `kimi-k2.6`(권장)과 `kimi-k3`로 실제 API 테스트를 마쳤습니다.
    - 중국 계정이면 고급 설정의 Base URL에 `https://api.moonshot.cn/v1`을 입력합니다.
  - **소스에서 실행**: Node.js 22 이상, pnpm 11 환경에서 `pnpm install` → `pnpm dev`. 설치 파일은 `pnpm dist`로 만들며 `dist/`에 생성됩니다.
  - **테스트**:
    - `pnpm test`: 단위·화면 흐름
    - `pnpm test:e2e`: 실제 Electron 앱으로 명세서 시나리오 1~8
    - `pnpm verify:packaged`: 설치본 실행 확인
